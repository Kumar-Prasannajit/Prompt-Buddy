# 🚀 PromptBuddy – Privacy-First AI Prompt Enhancer

**PromptBuddy** is a lightweight, privacy-first Chrome extension that helps you clean, clarify, and optimize messy or unclear prompts **before** sending them to AI tools like ChatGPT, Gemini, or Claude.

No accounts.  
No tracking.  
No data collection.  
Just better prompts.

---

## ✨ Why PromptBuddy?

Most AI prompt enhancers are websites that:
- Require sign-ups
- Log prompts on their servers
- Lock you into a single AI provider

**PromptBuddy is different.**

### 🔐 Built with privacy as a first-class feature
- Uses **your own API key**
- Runs directly in your browser
- No backend server
- No analytics
- No telemetry
- No prompt storage — ever

If you care about **security, privacy, and control**, PromptBuddy is for you.

---

## 🔧 Key Features

- ✍️ **Prompt Cleanup & Enhancement**  
  Fixes grammar, clarity, structure, and redundancy while preserving your intent.

- 🔁 **Multi-Model Support**  
  Choose between:
  - OpenAI (ChatGPT)
  - Google Gemini
  - Anthropic Claude

- ⚡ **Fast Workflow**
  - Enhance prompts with one click
  - Keyboard shortcut: **Ctrl / Cmd + Enter**
  - Instantly copy or insert into the active input field

- 🧠 **Configurable Output**
  - Set tone (professional, concise, etc.)
  - Control output length (max words)

- 🧩 **Works Where You Work**
  - Insert directly into ChatGPT, Gemini, Claude, editors, or any text field

## 🛡️ Privacy & Security (Read This)

PromptBuddy follows a **zero-telemetry, local-only design**.

✔ No prompt text is stored  
✔ No API keys leave your browser  
✔ No user tracking or identifiers  
✔ No backend servers  
✔ HTTPS only for AI API calls  

> **Your data stays on your machine. Always.**

This design intentionally eliminates entire classes of security and privacy risks.

## 📦 Installation (Developer Mode)

### 1. Add Icon Files
Create the following files in the extension root directory:
- `icon16.png`
- `icon48.png`
- `icon128.png`

> Tip: A prompt / edit / magic-wand style icon works well.

---

### 2. Load the Extension in Chrome
1. Open `chrome://extensions/`
2. Enable **Developer mode** (top-right toggle)
3. Click **Load unpacked**
4. Select the `promptBuddy` folder

---

### 3. Configure PromptBuddy
1. Click the PromptBuddy icon in the Chrome toolbar (Extension icon)
2. Open **Settings**
3. Select your AI provider:
   - OpenAI
   - Gemini
   - Claude
4. Paste your API key
5. (Optional) Set tone and max words
6. Click **Save**

---

### 4. Use PromptBuddy
1. Open the extension
2. Paste or type a messy prompt
3. Click **Enhance Prompt**  
   or press **Ctrl / Cmd + Enter**
4. Copy or insert the improved prompt directly into your AI tool

---

## 🔑 API Keys

You’ll need an API key from your chosen provider:

- **OpenAI (ChatGPT):**  
  https://platform.openai.com/api-keys

- **Google Gemini:**  
  https://makersuite.google.com/app/apikey (✅Recomended)

- **Anthropic Claude:**  
  https://console.anthropic.com/settings/keys

> Your API key is stored **locally** using Chrome’s storage and is never shared.
